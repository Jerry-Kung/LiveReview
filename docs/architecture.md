# 系统架构

> 记录稳定的系统级信息：系统边界、核心模块职责、分层与数据流、外部依赖、关键技术约束。
> 版本演进细节、任务级实现取舍见 `docs/specs/`；本文只保留当前仍然成立的稳定事实。

## 系统边界

LiveReview V0 是前后端分离的单体单仓应用：前端为纯 SPA，后端为单进程 FastAPI 服务，业务数据落 SQLite，媒体相关的原始文件与切片落对象存储。系统聚焦用户上传后的离线复盘，不包含实时直播接入、多实例部署与横向扩展；具体业务范围见仓库根目录 `README.md`。

## 核心模块职责

- **`backend/app/config.py`**：统一的配置入口，所有环境差异（服务地址、数据库、对象存储凭据、媒体工具路径）通过环境变量注入，凭据类字段无默认值。
- **`backend/app/database.py`**：SQLAlchemy 引擎与会话工厂，只负责数据库接线与连通性探测，业务模型由后续版本按需添加。
- **`backend/app/routers/`**：HTTP 路由层，聚合各基础设施模块的状态供探针与前端使用（如 `/health`）。
- **`backend/app/storage/`**：对象存储的契约与实现，详见下节。
- **`frontend/src/`**：React SPA，当前仅承载服务状态展示，业务界面随版本推进补充。

## 分层与数据流

请求经由 FastAPI 路由层，按需读取 `config.py` 的配置与 `database.py` / `storage/` 等基础设施模块的状态，不直接持有全局可变状态（配置与存储实例均为进程内单例，通过工厂函数获取）。健康检查路由聚合数据库与对象存储两路状态，形成整体服务健康状态；此聚合逻辑是唯一读取多个基础设施模块状态并合成对外契约的位置。

## 对象存储

- **职责**：保存原始视频（V0.1.3 起）与中间切片（V0.1.5 起）；只承担存储与按需取回，不参与时间对应关系的正确性判断。
- **模块**：`backend/app/storage/`。`base.py` 定义契约与领域异常，业务代码只依赖契约；`tos_backend.py` 为火山引擎 TOS 实现；`mock.py` 为本地内存实现，供本地开发与单测；`__init__.py` 的工厂按 `STORAGE_BACKEND` 选择实现。
- **选择规则**：`auto`（默认）有完整凭据时用 TOS，否则回落 Mock 并记录 warning；`tos` 强制真实，缺凭据直接报错；`mock` 强制内存。
- **对象键约定**：`{TOS_OBJECT_PREFIX}{kind}/{文件名主体}_{毫秒时间戳}_{8位随机串}{扩展名}`；`kind` 区分用途（`original` 原始视频、`clip` 切片）。
- **凭据约束**：AK/SK 仅从环境变量读取，不落代码、不落仓库、不进日志；预签名 URL 同样不进日志。
- **异常约定**：SDK 异常在实现内统一映射为 `StorageClientError` / `StorageServerError`；服务端错误保留 `code`、`request_id`、`status_code`，`request_id` 写入日志用于向服务商定位问题。

## 外部依赖

- **火山引擎 TOS**：对象存储服务商，通过官方 SDK 接入，仅测试环境具备真实凭据。
- **SQLite**：V0 阶段的业务存储，通过 SQLAlchemy 接入；数据库产品的长期选型见 `README.md` 第 5 节，随业务量演进重新评估。
- **FFmpeg / ffprobe**：媒体探测与转码工具，V0.1.4 起接入，只在测试环境（Docker 镜像）安装，本地不部署。

## 关键技术约束

- 敏感凭据（TOS AK/SK 等）只从环境变量读取，禁止出现在代码、日志与仓库中。
- 配置与对象存储客户端均为进程内单例，通过工厂函数获取，避免重复初始化或全局可变状态散落各处。
- 测试环境通过 Docker Compose 部署；后端不直接向宿主机暴露端口，前端容器是唯一外部入口。
- 本地开发不依赖 Docker、不依赖真实 TOS 凭据、不依赖 FFmpeg；这三类能力的真实验证统一在测试环境执行。
